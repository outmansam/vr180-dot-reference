# 制作 VR180 投影参考点阵

1. 获取用户上传图的实际文件路径。用户只传一张图并调用本 Skill 时直接处理，无需再问比例。若只有截图预览且找不到原始文件，先尝试获取附件文件。仍无法获取时，请用户传原图。
2. 使用本 Skill 的 [生成脚本](scripts/make_dot_reference.py)。用 Python 3.9+ 运行，确保终端的 PATH 能找到 FFmpeg 和 ffprobe。支持 PNG、JPG、JPEG 和 WebP。用 Windows 的 Python Launcher 时将 `python3` 替换为 `py -3`。
3. 给每张图指定一个独立的 `-o` 输出路径，格式为 `原名-dot-reference.png`。未指定输出位置时，用当前工作目录里用户可打开的位置。对多图逐张运行，保持原文件名可对应。路径已占用时改用有版本号的文件名，保留既有结果。
4. 读取脚本返回的画布尺寸、中心图尺寸和坐标。检查画布为 2048 × 2048，素材长边为 1024，完整居中。方图中心为 1024 × 1024，标准 16:9 横图中心为 1024 × 576。交付生成的 PNG 链接。有画面时核对中心图方向和边缘，并保留原始素材。

```bash
python3 "/path/to/make-vr180-dot-reference/scripts/make_dot_reference.py" "/path/to/input.png" -o "/path/to/output/input-dot-reference.png"
```

沿用脚本内的原版白底、左右灰色弧形点阵和边缘刻度。上下短刻度随素材高度调整。素材按像素比例缩放，保留透明度，不裁切、不拉伸、不补画。点阵参照 180° × 180° 等距柱状投影（ERP）的坐标，成品用于构图与生成参考。若用户要 VR 头显可播放的原生全景图，另按其实际素材投影处理，别把这张参考 PNG 当成原生全景交付。
